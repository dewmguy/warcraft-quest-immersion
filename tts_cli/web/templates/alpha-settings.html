What is reusable

Voice profile
Our race/gender or unique-NPC definition, history, references, and delivery presets.
Provider voice ID
The reusable ElevenLabs voice created from an approved design preview or clone. It is shown only after it exists.
Design seed
An optional API integer for repeating a Voice Design attempt; it is not the reusable voice itself.
TTS seed
An optional best-effort repeatability value for one speech request; determinism is not guaranteed.
Eleven v3 is the active default. It uses audio tags and stability for delivery; similarity, style, speaker boost, and numeric speed are not exposed when the selected model does not support them.
Preflight estimates

What a paid action means

Every speech button shows an estimate before it can contact ElevenLabs.

Meter

Speech is metered by characters, not LLM tokens. The app shows the exact text length before a request and records the provider's character-cost afterward when available.

Published API rate

Eleven v3 and Multilingual v2 are estimated at $0.10 per 1,000 characters. Your included plan usage or contracted rate can make the actual cash impact different.

Audio duration

Budget roughly one minute of finished speech per 1,000 characters. Delivery, pauses, audio tags, and punctuation can make the real file shorter or longer.

Request wait

The alpha allows up to three minutes for generation. Voice Design returns three candidates and charges the preview text once; saving one candidate uses a voice slot.
