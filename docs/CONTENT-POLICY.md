# Content and rights policy

## Project operating position

The project owner identifies this as a noncommercial, transformative fan work
intended to add immersion and value to an existing Warcraft experience. The
project is not intended to defame, substitute for, or commercially exploit the
underlying game or performances. The owner directs the project on the basis
that its addon and audio payload fall under fair use.

This file records the owner's operating position and is not an independent
legal opinion.

## Provenance requirements

Availability of a file and permission to use it for a particular processing
step are tracked separately. Imported audio, reference clips, generated takes,
and production files must retain their source, immutable hash, intended use,
and any applicable review notes.

Third-party service requirements remain separate operational constraints. A
file may be retained as an imported addon asset while being excluded from a
particular provider workflow if that provider does not permit the requested
use.

## Storage policy

Processed audio is excluded from Git. Git stores only code, source manifests,
hashes, metadata, dictionaries, reports, and reproducible import/package
tooling. Imported and generated audio remains in backed-up persistent storage.
