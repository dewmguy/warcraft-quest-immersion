# Warcraft pronunciation dictionary

`warcraft-en-US.csv` is the editable source of truth. The first owner review is
complete: all 61 retained entries are approved, and terms removed during that
review are not reintroduced by the build.

Run:

```powershell
python scripts/build_pronunciation_dictionary.py
```

The build produces two PLS files:

- `warcraft-en-US-ipa.approved.pls` for ElevenLabs models that support
  IPA pronunciation dictionaries.
- `warcraft-en-US-alias.approved.pls` for models that require readable
  alias substitutions.

Only rows marked `approved` are emitted into either PLS file. Pending and
rejected entries remain reviewable in the CSV but cannot silently enter a
generation dictionary.

`legacy-term-candidates.csv` is generated by `scripts/analyze_legacy_pack.py`.
It ranks possible future entries found in the imported NPC, gossip, and quest
lookup metadata. It is evidence for expansion, not an active dictionary.

When reviewing `warcraft-en-US.csv`, edit the IPA and alias as needed and set
`review_status` to `approved`. Notes should identify uncertainty or a canonical
spoken reference when one is available.
